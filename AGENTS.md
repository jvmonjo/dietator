# Agent instructions

- Use semantic commit messages for every commit title.
- Commit titles must follow Conventional Commits: `<type>(optional-scope): <description>`.
- Allowed types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.
- Keep variable names and code comments in English.
- Run lint, typecheck and test after code changes.
